## 구조 결정

### 1. 내용: DB·관리자 페이지 대신 저장소 파일

**왜:** 첫 버전(2026.01)은 FastAPI·PostgreSQL 백엔드와 관리자 페이지로 내용을 관리했습니다. 글 하나를 고쳐도 관리자 페이지와 DB를 거쳐야 했고, 내용이 DB에 있어 바뀐 기록이 저장소에 남지 않았습니다.

**바꾼 구조:** 프로젝트·글·프로필을 Markdown·YAML로 옮기고, 빌드할 때 작은 Vite 플러그인이 읽어 화면에 넘깁니다.

**결과:** 파일을 고쳐 머지하면 사이트에 반영되고, 고친 내용이 커밋 기록으로 남습니다. DB와 관리자 페이지는 필요 없어졌습니다.

## 탭 아이콘을 정한 과정

브라우저 탭에 뜨는 작은 아이콘(파비콘)을 시안 두 차례를 거쳐 정했습니다. 크게 그린 모양만 보고 고르지 않고, 실제로 보이는 크기와 밝은·어두운 탭에 넣어 비교했습니다.

### 1. 문제: 탭에 기본 지구본 아이콘

화면을 다시 만든 뒤에도 탭 아이콘이 없었습니다. 설정이 없는 파일을 가리키고 있어서 브라우저가 기본 지구본을 대신 보여 줬습니다.

![탭 아이콘을 넣기 전과 넣은 뒤의 브라우저 탭](/images/projects/portfolio/favicon-before.png)

### 2. 1차 시안: 사이트 색에 맞춘 네 가지

사이트의 흑백 톤, 라임색, 맨 위 점 무늬에 맞춰 네 가지를 만들었습니다. 시안마다 큰 모양, 32px·16px 크기, 밝은 탭과 어두운 탭에 들어간 모습을 나란히 놓았습니다.

![1차 시안 A, B, C, D](/images/projects/portfolio/favicon-round1.png)

- **A · J 모노그램:** 가장 단순하고 16px에서도 또렷합니다.
- **B · 도트 J:** 맨 위 점 무늬와 이어지지만, 16px에서는 점이 뭉개져 J로 읽히지 않습니다.
- **C · 한글 '주':** 첫 화면의 "주환" 원과 짝이 맞습니다.
- **D · J와 라임 커서:** 사이트의 라임색이 들어가 다른 J 아이콘과 구별됩니다.

### 3. 기준 다시 잡기: 실제 사이트 13곳 조사

1차 시안은 이 사이트의 색에만 맞춘 것이어서, 요즘 실제로 쓰이는 방식을 확인했습니다. 개발자 개인 사이트와 제품 사이트 13곳의 파비콘을 받아 16px 크기로 나란히 놓고 비교했고, 2026년 로고 흐름을 다룬 글도 함께 읽었습니다.

개인 사이트들은 거의 네 방식 중 하나였습니다.

| 방식 | 확인한 사이트 |
|---|---|
| 검은 원이나 사각형 안에 글자 하나 | rauchg.com, dillion.io |
| 색 하나로 된 단순한 도형 | rauno.me, emilkowal.ski |
| 본인 얼굴이나 캐릭터 | leerob.com, joshwcomeau.com |
| 손으로 그은 듯한 한 획 글자 | paco.me |

글들이 공통으로 꼽은 조건은 세 가지였습니다. 단순하되 개성이 있을 것, 16px에서도 또렷할 것, 다크 모드에서도 보일 것.

### 4. 2차 시안과 선택

조사한 방식에 맞춰 네 가지를 다시 만들었습니다.

![2차 시안 E, F, G, H. F를 선택](/images/projects/portfolio/favicon-round2.png)

- **E · 한 획 J:** 배경 없이 한 획으로 그은 J입니다. 다크 모드에서는 흰 선으로 바뀝니다.
- **F · 원 안의 J와 라임 점:** 검은 원 안에 글자 하나를 넣는 방식입니다.
- **G · 라임 구슬:** 글자 없이 색 하나만 씁니다. 탭 줄에서 가장 눈에 띄지만 이름과 이어지지 않습니다.
- **H · 에이전트 그래프 J:** J 획 위에 점 세 개를 올려 에이전트 구조를 담았습니다. 작게 보면 위쪽 점 두 개가 눈처럼 보여 얼굴로 읽혀서 제외했습니다.

**F를 고른 이유**

- 첫 화면의 "주환" 원과 모양이 같습니다.
- 16px에서도 라임 점이 보여 다른 J 아이콘과 구별됩니다.
- 이 사이트 템플릿을 만든 dillion.io와 같은 방식이라 화면 전체와 어울립니다.

### 5. 적용: 로고 하나를 세 곳에

![브라우저 탭, 아이폰 홈 화면, 링크 미리보기에 들어간 로고](/images/projects/portfolio/favicon-applied.png)

- **브라우저 탭:** SVG로 넣고, SVG를 읽지 못하는 환경을 위해 32px ICO를 함께 둡니다.
- **아이폰 홈 화면:** iOS가 모서리를 직접 둥글게 깎으므로, 원 대신 꽉 찬 검은 사각형에 같은 글자를 넣었습니다.
- **링크 미리보기:** 카톡이나 링크드인에 주소를 보내면 뜨는 이미지에도 같은 로고를 썼습니다.
